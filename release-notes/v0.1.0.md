# v0.1.0 — Initial Standalone Microsoft OneNote Release (`@bitefoundry/onenote`)

Version `0.1.0` launches **`onenote`** / **`note`** (`@bitefoundry/onenote`), a standalone **Microsoft OneNote** terminal client, CLI, HTTP API server, and MCP server built in Rust on Microsoft Graph v1.0, local SQLite WAL + FTS5 caching, and Minimal-Chrome terminal UX.

## Highlights

- **Complete Microsoft OneNote Engine (Personal, Group/Teams, SharePoint Site Scopes)**:
  - **Hierarchy & Pages**: Full notebook, section group, section, and page listing across `/me/onenote`, `/groups/{id}/onenote`, and `/sites/{id}/onenote`, with nested subpage indentation (`level 0/1/2`) and custom section tab colors.
  - **Bidirectional XHTML ↔ Markdown Parser**: Lossless OneNote XHTML parsing into structured blocks (`Heading`, `Paragraph`, `BulletList`, `NumberedList`, `TodoItem`, `Table`, `CodeBlock`, `Image`, `FileAttachment`, `Quote`, `Divider`, `UnknownHtml`), surgical `PATCH` generation (`data-id` / `generatedId` block replacement, `data-tag="to-do:completed"` toggling, body append, title & full-body replace), and `multipart/form-data` image uploads (`<img src="name:img-1" />`).
  - **Local SQLite WAL + FTS5 Cache**: Fast offline browsing and full-text search across cached page titles, Markdown bodies, and sections (`onenote_notebooks`, `onenote_section_groups`, `onenote_sections`, `onenote_pages`, `onenote_fts`).
- **Minimal-Chrome Responsive TUI (`ratatui`)**:
  - Dedicated 3-column OneNote workspace: Notebook Sidebar + Colored Horizontal Section Ribbon + Action Toolbar + Page List + Rich Note Canvas.
  - Inline terminal image previews (Kitty / iTerm2 / Sixel / 24-bit Half-Blocks with 80ms capability probe, Lanczos3 downscaling, and Floyd-Steinberg Sixel dithering) for embedded OneNote page images (`<img src=".../resources/...">`) plus fullscreen HD preview (`v`).
  - `u` Link Extractor modal + `h` inline `href` toggle, `Ctrl+V` clipboard PNG paste in OneNote forms, `Ctrl+F` interactive File Picker with `zoxide` jump (`z`), `Ctrl+,` Settings modal, `.` / right-click Context Menu, `Ctrl+P` Command Palette, persistent `DraftStore`, and desktop notifications.
  - 100% English UI across all views, modals, toasts, and status bars, with colorblind-safe themes (`Midnight Dark`, `Daylight Light`, `Ansi256`, `Ansi16`, `NO_COLOR`).
- **Agent-Native Interfaces (`onenote`, `onenote serve`, `onenote mcp`)**:
  - **CLI**: `notebooks`, `sections`, `pages`, `read`, `create-notebook`, `create-section`, `create`, `append`, `update`, `check`, `delete`, `search`, `resource` (`{ ok, path, file_name, mime_type, size_bytes, is_image }`), `sync`, `daemon`, `serve`, `mcp`, `tui`, `preview-file`, `self-update`.
  - **Local HTTP API (`onenote serve`, default `127.0.0.1:8788`)**: `/health`, `/v1/whoami`, `/v1/onenote/*` (plus `/onenote/*` aliases), and OpenAPI 3.1 contract (`docs/openapi.yaml`).
  - **MCP Server (`onenote mcp`)**: Stdio JSON-RPC 2.0 server exposing `whoami` + 13 OneNote tools (`list_notebooks`, `list_sections`, `list_pages`, `get_page`, `create_notebook`, `create_section`, `create_page`, `append_page`, `update_block`, `toggle_todo`, `delete_page`, `search_pages`, `download_resource`).
- **Shared IPC Sync Daemon & Native Packaging**:
  - Single-instance background sync daemon (`onenote daemon start | status | stop | restart | run`) over authenticated loopback / Unix socket IPC.
  - Cross-platform `@bitefoundry/onenote` npm distribution (`win32-x64`, `win32-arm64`, `darwin-x64`, `darwin-arm64`, `linux-x64`, `linux-arm64`) installing both `onenote` and `note`, with `GLIBC 2.28` compatibility and SHA-256 verified self-updates.
