## What's Changed

### Native-Terminal Input Latency & Event Loop Fix
- Replaced `crossterm::event::EventStream` and `.now_or_never()` polling with a dedicated lock-free `TerminalEventReader` (OS reader thread + Tokio `mpsc::unbounded_channel`), eliminating both `noop_waker` poisoning (up to 200ms timer-tick stalls) and Windows `INTERNAL_EVENT_READER` mutex blocking on every keystroke.
- Wrapped terminal output in a 64 KiB `BufWriter<Stdout>` and moved cursor positioning inside `terminal.draw()` (with queued `BeginSynchronizedUpdate`), removing redundant per-keystroke Hide/Show cursor flicker and multiple stdout flushes.
- Paused and resumed the dedicated reader cleanly around external `$EDITOR` handoff and Windows `Resize` VT probing.

### Direct In-Place Canvas Editor & 0ms Optimistic Writes
- Added a direct in-place Markdown canvas editor (`src/ui/inline_editor.rs`) backed by `ComposerState` with 2D cursor navigation, Korean IME hardware cursor placement, Undo/Redo, clipboard paste, `Ctrl+E` external `$EDITOR` handoff, click-to-edit on canvas/blocks, and 1.5s debounced background Graph autosave.
- Applied 0ms optimistic UI updates for inline saves, quick appends, and To-Do toggles so edits reflect immediately without waiting for Graph round-trips.
