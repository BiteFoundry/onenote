## What's Changed

### Binary Size, Build Diet & Rendering Consistency
- **Smaller Release Binaries**: Enabled `opt-level = "s"` and `panic = "abort"` in `[profile.release]`, cutting release binary sizes by ~40% with zero feature loss.
- **Parser / UI Consistency & Hardening**: Unified drifted `spans_to_markdown` rendering onto the canonical parser implementation, hoisted `Selector::parse("body")` to a `LazyLock`, boxed oversized enum variants (`Overlay`, `PageResolution`), hardened production `unwrap()` sites, removed dead legacy code, and resolved all Clippy warnings (`-D warnings` clean).
- **Dependency & Packaging Diet**: Upgraded `ratatui` to `0.29`, `dirs` to `6`, and trimmed `bitefoundry-html` `resvg` features; removed unused `crossterm/event-stream`, `futures`, `hex`, and `uuid`, moved `tempfile` to dev-dependencies, and added optional Cargo feature gates (`html-js`, `svg-graphics`, `desktop-notify`) for lightweight headless builds.
- Externalized `assets/demo.gif` to `bitefoundry.dev` to keep repository clones lean.
