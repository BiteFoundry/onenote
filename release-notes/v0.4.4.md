## What's Changed

### Sync & Graph Latency Optimization
- Added `list_all_accessible_hierarchy_scoped` to fetch personal `/me/onenote/notebooks`, `/me/onenote/sections`, and `/me/onenote/sectionGroups` concurrently in a single parallel round-trip (and overlapped `/me/joinedTeams` on org accounts).
- Parallelized `get_me`, focused section pages, and focused page hydration via `tokio::join!` inside `run_full_refresh`, cutting TUI startup active-view load time in half.
- Memoized `pagelevel=true` HTTP 400 fallback per `GraphClient` instance via `Arc<AtomicBool>` to skip repeated failing probes.

### Write Path & TUI Perceived Latency
- Updated `append_onenote_page_helper` to reuse cached `primary_div_id` from SQLite first (skipping a redundant 3.5s remote pre-fetch) with automatic single refresh-and-retry on stale target errors (`400`/`404`/`410`).
- Rendered locally compiled XHTML previews immediately on `UiMsg::PageCreated` while background `HydratePage` upgrades Graph `data-id` attributes.
- Added bounded, budgeted background prefetching of up to 4 uncached sibling pages in the active section so `j`/`k` page switching renders instantly from SQLite.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory (`#[cfg(test)]`).
