## What's Changed

### WYSIWYG Rendered Default Editing & 3-Mode Toggle (`Ctrl+M`)
- Added full WYSIWYG **Rendered** editing (`EditorMode::Rendered`, pill `[Render]`) as the new default mode: the active cursor line stays cleanly rendered while typing with exact ASCII + Korean/CJK hardware cursor projection onto rendered glyphs.
- Added `Ctrl+M` / clickable header pill cycling across **`[Render]` → `[Live]` → `[Src]`**.
- Added WYSIWYG cursor ergonomics in `[Render]` mode: `←`/`→` skip hidden Markdown delimiters, `Home` lands on visible content start, `Backspace` unwraps block prefixes in one atomic undoable edit, and emptying inline formatting cleans up empty orphan delimiter pairs (`****`, `~~~~`, `` `` ``).

### 0ms Optimistic Block Updates & `Esc` Visibility Fixes
- Added 0ms optimistic local preview updates for `InlineEditTarget::Block` (pages with embedded images/multi-div regions) so edits no longer disappear on `Esc` while Microsoft Graph sync completes.
- Synced `onenote_selected_block` and `onenote_follow_selection` on `Esc` so edited text stays in view, and prevented bare `# ` headings from turning invisible on inactive lines.
