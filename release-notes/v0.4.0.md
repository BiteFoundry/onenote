## Changes

Page commands can use a section to disambiguate duplicate page titles. Section-scoped search accepts scoped keys and notebook paths, and concurrent edits retain their original comparison baseline.

## Compatibility

- `append`, `update`, and `check` with `--json` now return a summary with `ok`, `page_key`, `title`, and `last_modified_at`. If your script reads `.page`, add `--full` to the write command.
- In MCP, pass `"compact": false` to `append_page`, `update_block`, `update_page`, or `toggle_todo` to include the full `page` object.
