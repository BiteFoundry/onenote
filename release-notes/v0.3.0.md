Page detail is compact by default in `onenote read <page> --json` and MCP `get_page`. It includes the page key, scope and a hint for retrieving omitted content. Request the expanded document with `--json --full` or `compact: false`.

Local search reuses the cache for the identified account. When an opaque access token has no recorded identity, run `onenote whoami` once online to bind it before using local search.

JSON and MCP notebook and section lists return 50 items by default and provide a continuation cursor. Offline results expose the cache sync state.
