## What's Changed

### Terminal Image Preview Quality & Protocol Detection
- Replaced fixed low-resolution downsampling and stretched aspect-ratio math with terminal cell-geometry sizing and unified protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in OneNote page/attachment rendering via pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` graphics, with an explicit `[o: Browser]` banner for external `<script src>` content.

### Unified Markdown Rendering & `.md` Preview
- Standardized Markdown parsing on `pulldown-cmark 0.13` via `bitefoundry-html::markdown` and enabled in-TUI `.md` previewing.

### Width-Aware Text Wrapping & Full Table Cell Preservation
- Removed the 4-line table cell truncation (`.take(4)`) in `onenote_view` and migrated page bodies, callouts, code blocks, tables, and form overlays to display-width-aware styled wrapping so all rows, columns, and lines remain visible at any terminal width.

### TUI Modal Isolation, Ribbon Mouse & Mutation Sync Guards
- Isolated modal backdrops, fixed form/ribbon mouse handling, added mutation sync guards, and added Docker / MCP Registry (`server.json`) packaging.
