Edit text inside a multi-region page while preserving other regions. Repeating a checklist request sets the requested state. Compact reads return the page Markdown.

Copy a page to another section with `onenote copy-page` or MCP `copy_page`. Graph creates a new page and retains the original. A pending copy can be resumed with its operation URL.

Rename sections and notebook drive items. OneNote for Windows also supports desktop page indentation and section renaming.
