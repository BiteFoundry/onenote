## What's Changed

### OneNote Line Live Preview Direct Canvas Editor
- Upgraded `OnenoteInlineEditor` to **Line Live Preview** mode by default (`EditorMode::LivePreview`, toggleable with `Ctrl+M` or the clickable `[Live]`/`[Src]` header pill): inactive lines render styled Markdown (headings, `☐`/`☑` tasks with completed strikethrough, bullet/numbered lists, quote bars, horizontal dividers, fenced code blocks, bold/italic/code/strike, and styled links) while the active cursor line expands to raw syntax-highlighted Markdown with exact ASCII + Korean/CJK hardware cursor positioning.
- Clicking any rendered line in Live Preview maps the visual position accurately to the logical line and byte offset, expanding the clicked line and collapsing the previous line immediately while preserving 0ms optimistic UI writes and 1.5s debounced background Graph autosave.
