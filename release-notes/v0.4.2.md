## What's Changed

### Selective `fields` Projection on `get_page`
- Added optional `fields: [...]` projection to MCP `get_page` so agents can fetch specific fields (`blocks`, `resources`, `web_url`, `created_by`, `body_markdown`, etc.) by page ID without pulling full `raw_xhtml` via `compact: false`, with `missing_fields` reporting.

### Symlinked `$HOME` & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module guard via `fs.realpathSync` so native binary linking runs reliably when `$HOME` or the npm prefix is a symlink.
- Canonicalized daemon UDS hashes and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` (while refusing `0600` secret symlinks), expanded `~/` on `ONENOTE_CONFIG_DIR`/`ONENOTE_DATA_DIR`/`TEAMS_CONFIG_DIR`/`$EDITOR`, and resolved symlinked binaries in `updater.rs`.
